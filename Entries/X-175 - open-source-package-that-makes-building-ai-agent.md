# Open-source package that makes building AI agents 10x easier

**[Open original ↗](https://x.com/DhravyaShah/status/1806379496917827774)** · `Dhravya Shah` · 2024-06-27 · 5 replies · 308 likes · 38.3K views

## 💬 Essence

OP announces an open-source package for building AI agents - Google Calendar chat agent, GitHub agent, updating Notion/Airtable from prompts, using D1 and KV - and the self-thread details `runWithTools`: you supply prompts and functions, it asks the AI for arguments, runs them and returns a natural-language response, removing the argument and error handling developers previously wrote by hand (all on Workers, keeping their latency advantages). Because writing tools in JSON Schema is still painful, a second helper generates all the tools automatically from an OpenAPI specification. No reply digest was captured despite 5 replies.

## 💡 Takeaway

Agents-SDK launch; the OpenAPI-to-tools helper is the interesting DX idea here.
