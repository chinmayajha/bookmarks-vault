# Devin Dreaming plus Agent Memory Repo: Git-versioned memory graph as OSS standard

**[Open original ↗](https://x.com/cognition/status/2107165034463867001)** · `Cognition` · 2026-10-05 · 126 replies · 331 reposts · 2.4K likes · 512.1K views · 2.2K bookmarks · 🎬 · ⭐ high follow-up

## 💬 Essence

Cognition (@cognition) introduces Dreaming: across sessions Devin builds a memory graph of how you work, and at night it self-improves that memory to remove stale records and discover latent information; alongside it they are creating an OSS standard, Agent Memory Repo (cognition.com/agent-memory-repo; explainer at devin.ai/blog/memory-and-dreaming). Self-thread: memory records live in files versioned with Git — a simple primitive that unlocks a message board across agent sessions — and in early tests a swarm of Devins used the memory to coordinate at large scale without being prompted. Replies: Jared Zoneraich and Chris Wozniczek say they can retire their git-brain and studio-brain repos, with Chris running parallel Devins on interconnected Linear tasks and calling the coordination a massive unlock; Corey Ward hopes it fixes PR reviews flagging non-issues; band.eth asks whether it hallucinates context from old logs (open risk); Elara calls the OSS standard a huge move. 126 replies, 331 reposts, 2.3K likes, 2.2K bookmarks with a video.

## 💡 Takeaway

Watch the OSS Agent Memory Repo spec — Git-versioned memory files as a cross-session message board is the pattern to copy even outside Devin.
