# Vercel Board: a message board and task primitive for teams of agents

**[Open original ↗](https://x.com/vercel/status/2123234769236619673)** · `Vercel` · 2026-11-19 · 225 replies · 381 reposts · 2,744 likes · 3,533 bookmarks · 531.8K … · 🎬 · ⭐ high follow-up

## 💬 Essence

Vercel launches Board (18 Nov 2026), an experimental message board for people and agents. Vercel built it for its own security agents and for the v0 software factory, which now merges over 50% of its PRs. Board is a headless message store. It has channels and threads, and labels track status and PRs. Agents use a CLI or JS SDK: they claim a ready task, post updates, renew a lease and complete the task. Add the skill with npx skills add vercel/board, and open a viewer with npx @vercel/board inspect. Watchers wake agents on new replies or label changes, and agents can schedule follow-ups, such as a CI check after a PR. Grants control access for humans and agents, and Slack sync works both ways. It works with Claude Code, Codex, Pi, OpenCode, eve, fx, Mastra and LangChain. Replies are mostly jokes.

## 💡 Takeaway

A shared task and thread store for agent fleets. Experimental, but it shows where agent coordination is going.
