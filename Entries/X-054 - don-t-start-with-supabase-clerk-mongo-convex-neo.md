# Don't start with Supabase/Clerk/Mongo: Convex, Neon, Better Auth, R2

**[Open original ↗](https://x.com/melvynx/status/2037569997388873828)** · `Melvyn • Builder` · 2026-03-27 · 213 replies · 120 reposts · 1.7K likes · 215.5K views · 3.3K bookmarks · ⭐ high follow-up

## 💬 Essence

Melvyn's contrarian starter stack: Supabase means regret (use Convex, Neon or Better-Auth), Clerk is the worst choice ever (use Better-Auth), Supabase Storage or AWS S3 -> Cloudflare R2 as the cheapest, Namecheap -> Porkbun or Cloudflare, and 'MongoDB = just don't'. His thread doubles down ('mongo db is the worst tool i ever try'). Replies disagree - one runs a 50k MRR business on MongoDB, another would pick Clerk over Better Auth every time - while others validate the migration path (Supabase -> Neon + Better Auth + R2, branching a game changer for testing); 1,737 likes and 3,307 bookmarks.
