# Moondream: small vision model; the free API in this post has ended

**[Open original ↗](https://x.com/moondreamai/status/1879610041499787618)** · `moondream` · 2025-01-15 · 55 replies · 1.5K likes · 197.9K views · ⭐ high follow-up

## 💬 Essence

The Jan 2025 post pitched swapping OpenAI for Moondream's free vision API in three lines of code. The thread gave the OpenAI-compatibility docs and a free API key, and said the catch was 5,000 queries per day. It also noted that the 2025.1.9 release improved text OCR and understanding. Update, 26 Nov 2026: console.moondream.ai no longer resolves and the free daily API is gone. moondream.ai now lists the open models and the Photon engine as free to run. The hosted Cloud costs per token (Moondream 3.1 9B A2B real-time: $0.30 per 1M input and $1.00 per 1M output tokens). The free plan includes $5 of usage credits each month.

## 💡 Takeaway

Moondream is still worth a try for small vision tasks, but budget for per-token pricing and not a free daily quota.
