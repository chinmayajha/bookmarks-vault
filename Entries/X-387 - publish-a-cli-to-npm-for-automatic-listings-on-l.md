# Publish a CLI to npm for automatic listings on Libraries.io and more (DR 75)

**[Open original ↗](https://x.com/tarasshyn/status/2112893275933741142)** · `Taras` · 2026-10-20 · 3 replies · 1 reposts · 82 likes · 177 bookmarks · 7.9K views

> ⏰ **Important:** Ahrefs rolls out its DR4 rating model on 1 Dec 2026. DR numbers quoted in these SaaS visibility hacks can change, so check your own DR before then. · ⏳ by 2026-12-01

## 💬 Essence

Taras says another visibility hack for a SaaS is to create a CLI, because npm directories such as Libraries.io (DR 75) pick it up automatically. Step 1: have a public API. Step 2: wrap it in a small CLI with a login command that takes an API key and one command per main action (ask Claude to write it). Step 3: fill in name, description, keywords, homepage and repository in package.json. Step 4: run npm publish --access public. It is then picked up by npm.io, Libraries.io, jsDelivr, Google's deps.dev and others, and some customers prefer a CLI to an API or MCP. Replies agree and add MCP servers as another listing route. In the replies, an Ahrefs account says it is releasing a preview of DR4, a new Domain Rating model, and DR may change when it rolls out on 1 Dec, with subdomains getting their own rating. This matters because every hack in this series quotes DR numbers. Another reply argues that in 2026 you should start an AI-enhanced productized service, not a SaaS.

## 💡 Takeaway

A small CLI is cheap distribution. The DR scores quoted across the series may shift after Ahrefs rolls out DR4 on 1 Dec 2026.
