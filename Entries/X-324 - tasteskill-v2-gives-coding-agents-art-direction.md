# TasteSkill v2 gives coding agents art direction, real assets and a browser check

**[Open original ↗](https://x.com/LexnLin/status/2110122106537050584)** · `Leon Lin` · 2026-10-13 · 94 replies · 279 reposts · 4.6K likes · 8.7K bookmarks · 542K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Leon Lin rebuilt TasteSkill from scratch: v2 reads a brief, writes down what is specific to that client, has a script choose three directions from twenty it researched, and then makes the agent gather real photos, maps and other assets with credits before building. A browser check verifies the result instead of trusting the model's self-report. The install is npx skills add Leonxlnx/taste-skill, and the repo includes example credits. Lin is candid that it is 'just some markdown files' and cannot solve general design taste, and the replies bear that out - some call it their go-to skill, others say the showcased outputs still look like AI slop. The launch video was itself coded with Cinetic and Opus 5.5.

## 💡 Takeaway

The strongest part is the workflow - research, constrained direction choice, real assets, browser verification - not a promise that markdown can replace a designer.
