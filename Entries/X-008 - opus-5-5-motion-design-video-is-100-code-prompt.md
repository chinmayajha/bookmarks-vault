## 💬 Essence

zero claims Opus 5.5 is cracked at motion design: the entire video is code with zero After Effects, and he open-sources the prompt template so anyone can recreate it. The template asks the model for 8-12 UI states (button, loader, player, slider, toggle, tabs, chart, command palette, toast), one shape that morphs between states with springs, a cursor driving real clicks and drags, Geist font on a light warm-gray canvas, a royalty-free ~120BPM track, and a last frame equal to the first.
