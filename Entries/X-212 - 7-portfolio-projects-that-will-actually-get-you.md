# 7 portfolio projects that will actually get you hired

**[Open original ↗](https://x.com/sandeep_jain/status/1572925652042657792)** · `Sandeep Jain` · 2022-09-22 · 24 replies · 1.6K likes

## 💬 Essence

OP lists seven coding projects to add to a portfolio that will actually get you hired: a food delivery app, an e-commerce store prototype, a messaging app, a simple game, a chatbot, a dating app and a video chatting app. Replies confirm those project types are always in demand, plan to build them all in Flutter, and point out that each demonstrates authentication, state management, UX understanding and some security - which is exactly what interviewers look for.

## 💡 Takeaway

Canonical junior portfolio checklist; replies spell out what each project actually proves.
