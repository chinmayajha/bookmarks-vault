# pnpm asks your coding agent to fix its 629 open issues

**[Open original ↗](https://x.com/pnpmjs/status/2103438679478010198)** · `pnpm` · 2026-09-25 · 33 replies · 60 reposts · 567 likes · 61.7K views · 266 bookmarks

## 💬 Essence

pnpm invites people to spend tokens on open source: 629 open GitHub issues plus a ready-made prompt to feed a coding agent, with Windows-repro issues especially wanted. The thread notes PR quality stays high thanks to strict linting, test coverage, benchmarks, AI code review and human-reviewed decisions, that the repo has never been in better shape, and points at open PRs to review. Replies push back on how they triage 'prompt slop' (OpenClaw hit the same problem), question how many issues survive GitHub filters once has-PR, in-progress, blocked and needs-design are excluded, and one person found their picked 2025 issue already fixed on main; others call it a genius move.

## 💡 Takeaway

A template for how maintainers channel AI coding agents at real issues - and the review/triage burden it creates.
