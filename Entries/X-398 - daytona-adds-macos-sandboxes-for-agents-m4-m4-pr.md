# Daytona adds macOS sandboxes for agents (M4, M4 Pro, M5 Pro)

**[Open original ↗](https://x.com/ivanburazin/status/2122721729512628713)** · `Ivan Burazin` · 2026-11-17 · 110 replies · 110 reposts · 725 likes · 596 bookmarks · 130.5K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Ivan Burazin announces that macOS Sandboxes are live on Daytona, on M4, M4 Pro and M5 Pro hardware, with the tagline that agents can finally use a Mac. His thread admits that bare metal is the cheapest way to get a Mac, but says you then do the setup, isolation, imaging and scaling yourself. He says Daytona does not compete on price. You get the whole Mac, and more is coming. Replies point to a bare-metal host that charges about 10 euros a day (macduty.com). One asks whether agents can run the iOS Simulator in these sandboxes, and the captured replies give no answer. Another asks whether these are VMs or full Macs.

## 💡 Takeaway

Useful when an agent needs Xcode, the iOS Simulator or macOS UI. Compare the price with a bare-metal host first.
