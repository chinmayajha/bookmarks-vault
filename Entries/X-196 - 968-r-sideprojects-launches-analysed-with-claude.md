# 968 r/SideProjects launches analysed with Claude 3 Opus

**[Open original ↗](https://x.com/alexanderisorax/status/1772249784251777384)** · `Alexander Isora, ex-maker` · 2024-03-25 · 16 replies · 645 likes · 238.8K views · ⭐ high follow-up

## 💬 Essence

OP parsed 968 launches from Reddit's r/SideProjects (posts starting with 'I built', 'I made an alternative to', 'I created a clone of') and had Claude 3 Opus analyse them, publishing the JSON. The self-thread reports the most-clone categories - website builders (29), dev tools (26), chrome extensions (21), finance (15), self-hosted (14), habit trackers (12), AI tools (108, 10.8%) - a 69.8% B2C vs 30.2% B2B split with a plea to do B2B, plus the most boring, inspiring, least catchy and catchiest launch titles, and an offer to run reader questions through Opus.

## 💡 Takeaway

Quantified snapshot of what side-project builders actually ship - useful idea-space competitive data.
