# agent-desktop: accessibility-tree computer use for agents on macOS, Windows and Linux

**[Open original ↗](https://x.com/mdlahfir/status/2116316228046500348)** · `Lahfir ▲` · 2026-10-30 · 82 replies · 116 reposts · 1.6K likes · 1.4K bookmarks · 154K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Lahfir (Vercel Labs) introduces agent-desktop, installed with npm i -g agent-desktop. It reads apps through the accessibility tree, so agents can end-to-end test desktop apps. Skeleton-based drilling lets an agent snapshot only one region of a window, then drill deeper with find and wait to save tokens on long tasks. With --multi-agent and an --agent-id per agent, several agents share one desktop, each with its own cursor and label. It is headless by default, except for drag, menus and surfaces. It pairs with agent-browser (web) for full computer use, and can run inside a Vercel Sandbox on a Linux desktop in the cloud and return JSON. Docs are at agent-browser.dev/desktop. Replies report the .md docs URL returns 404 and ask for token counts for full-window versus drilled-down runs.
