# Pattern to learn anything with GPT-4

**[Open original ↗](https://x.com/waiting4_asi/status/1643892199333953538)** · `Varun Mayya` · 2023-04-06 · 21 replies · 685 likes · 44.5K views

## 💬 Essence

OP's prompt sequence for learning anything: ask for a broad summary of the field, ask it to explain a concept, ask again to explain like you're five, converse with it, then finish with 'ask me 3 questions about this topic and test my answers'. His self-thread adds a screenshot of the workflow, argues all you really need for slow-changing subjects is a high-quality up-to-date syllabus, and calls GPT a teacher that is permanently fun and never exhausted. Replies confirm it works for chemistry (you can ask the dumbest doubts), note that unlike school teachers it never shuts down follow-ups, and add a missing step - re-explain in your own words and ask GPT to find the gaps, which the poster uses to digest arXiv papers.

## 💡 Takeaway

Compact, tested prompt pattern for LLM-based learning, improved in replies.
