# A 0.62GB LoRA for the MiniMax H3 video model, trained on adult videos

**[Open original ↗](https://x.com/alizeh_ai/status/2123720008639578585)** · `Alizeh` · 2026-11-20 · 72 replies · 225 reposts · 3,183 likes · 8,047 bookmarks · 342.4K …

## 💬 Essence

Alizeh posts a free LoRA for the MiniMax H3 video model on Hugging Face (Sentinel7/h3). It is described as v3 'extreme realism' in one 0.62GB safetensors file, trained on almost 1,000 adult videos, with 91K downloads and no trigger word. Creator settings: euler, 18 steps, shift 12. It also works with a turbo LoRA, at your turbo step count. Replies add three points. It is only a LoRA, so you need the base H3 model, and the base sets the VRAM need. A .safetensors file holds weights and cannot run code, but .ckpt and .pt files can. One reader doubts the claims. Another asks who gave consent for the training data, and the author agrees that file size does not answer that.

## 💡 Takeaway

Adult-content model with open consent questions. Low priority. Keep only if you track video LoRAs.
