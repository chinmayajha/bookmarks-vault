# ChatGPT can now build and deploy MCP servers on ChatGPT Sites

**[Open original ↗](https://x.com/thsottiaux/status/2105519215092584786)** · `Tibo` · 2026-09-30 · 414 replies · 373 reposts · 4,990 likes · 768.8K views · 2,156 … · ⭐ high follow-up

## 💬 Essence

Tibo (OpenAI) quote-tweets Max Stoiber's launch to say you can now build and deploy MCP servers right through ChatGPT, then restrict their access to anyone you want or share them with the world; the quoted demo runs on '@sites create a todo list', which creates the MCP server, deploys it to Sites and turns it into a plugin. The quoted thread also carries Dishwasher's developer question about whether OpenAI-hosted infrastructure will eventually run backends for plugin extensions, since running a backend is the hard part. Captured replies turn skeptical: TEAGÁ 'nobody cares about Sites and Maps', Tucker King 'Hope people actually use the restrict button', and dearlordylord reporting a live approval bottleneck - his SRD 5e Oracle MCP 'is in approval loop for a month now' (a fourth captured reply is a spam ad). So the debate is about gating and distribution, not the tech. 414 replies, 4,990 likes, 2,156 bookmarks, 768.8K views.

## 💡 Takeaway

MCP servers become one-click hosted products inside ChatGPT - distribution for MCP builders just got much bigger; watch the hosting, permissions and backend story.
