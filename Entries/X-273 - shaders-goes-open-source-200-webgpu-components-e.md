# Shaders goes open source: 200+ WebGPU components, export code for any framework

**[Open original ↗](https://x.com/npm_i_shaders/status/2107467668009963819)** · `shaders` · 2026-10-06 · 66 replies · 251 reposts · 3K likes · 186.1K views · 3.8K bookmarks · 🎬 · ⭐ high follow-up

## 💬 Essence

shaders (@npm_i_shaders) open-sources 200+ WebGPU components — use in client sites, templates, products or libraries and export code for any framework, free (github.com/shader-effects-inc/shaders; announcement at shaders.com/updates/shaders-is-open-source). Self-thread adds the agent angle: coding agents write raw WGSL that underperforms in production, so building on production-tested components means better shaders, faster workflow and real performance. Replies show immediate adoption: Bin Liu is adding them to HyperFrames Studio today, Josh Millgate is adding shader backgrounds to ultramock, and TypeGPU's Iwo Plaza calls it a huge move; Audiencon notes open source plus exportable code removes framework lock-in. Post drew 66 replies, 251 reposts, ~3K likes, 3.8K bookmarks and 186K views with a video demo.

## 💡 Takeaway

Save the repo and announcement; the agents-building-on-tested-components framing is the reusable pattern for shipping WebGPU without hand-tuning WGSL.
