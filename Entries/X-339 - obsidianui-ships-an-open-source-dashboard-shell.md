# ObsidianUI ships an open-source dashboard shell after a three-hour build

**[Open original ↗](https://x.com/athrix_codes/status/2107718490585227657)** · `Athrix` · 2026-10-07 · 14 replies · 3 reposts · 147 likes · 137 bookmarks · 7.5K views · 🎬

## 💬 Essence

Athrix spent three hours building a dashboard component and released it as open source in ObsidianUI, with a live docs page at obsidianui.dev/docs/dashboard-shell and a GitHub repo. The pitch is aimed squarely at paid UI libraries - 'every paid ui lib will hate us' - and the component uses duotone icons and FactoryAI in the build. The thread is small but positive, with people asking about the icon pack and recording tool and one noting that three hours for a polished shell is a sweet spot. The repo is also being pushed toward 1,000 stars, so this is early-stage and worth watching rather than adopting blind.

## 💡 Takeaway

A free dashboard shell for fast internal tools; the three-hour build is impressive, but the library is young and lightly tested.
