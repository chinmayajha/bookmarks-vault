# Get docs scored on Fern's Agent Score for a public dofollow page (DR 77)

**[Open original ↗](https://x.com/tarasshyn/status/2113979571884429494)** · `Taras` · 2026-10-23 · 8 replies · 3 reposts · 106 likes · 240 bookmarks · 14.1K views

## 💬 Essence

Taras explains Fern's Agent Score as a visibility hack. Step 1: host docs on your own domain. Step 2: make them readable for agents with an llms.txt that lists every page and a .md version of each page. Step 3: check locally with npx afdocs. Step 4: go to buildwithfern.com/agent-score, click Score docs and paste the URL. The page goes live at once with your grade and a dofollow link to your docs, and you can request a leaderboard listing. Replies: a company says its docs got an A+; one reply says llms.txt has nothing to do with agentic scoring; Taras says Fern's score is easier to trick and points to Vercel's is-agentic.com as a better measure. The quoted post is a similar hack for a Postman public profile (DR 91).

## 💡 Takeaway

A quick way to test and publicize agent-readable docs. Treat the score as a signal, not proof.
