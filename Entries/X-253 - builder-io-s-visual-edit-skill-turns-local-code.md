# Builder.io's /visual-edit skill turns local code into a Figma-like canvas

**[Open original ↗](https://x.com/Steve8708/status/2105376370838974842)** · `Steve (Builder.io)` · 2026-09-30 · 27 replies · 62 reposts · 799 likes · 45.8K views · 1,082 bookmarks · 🎬 · ⭐ high follow-up

## 💬 Essence

Steve (Builder.io) announces /visual-edit, an open-source skill that opens a running local app as URL-backed iframe screens on a Figma-style canvas so agents and humans can make visual edits. The self-thread then hands over the source (github.com/BuilderIO/skills), points to Agent-Native Design, gives the install command (npx @agent-native/core@latest skills add visual-edit) and answers how edits travel: the agent gets a prompt back containing a diff plus metadata such as each element's origin line of code. The captured replies are few but substantive and map straight onto that thread - Logan asks whether an edit 'lands as a diff or as a prompt back to the agent' (the thread answers: a prompt carrying a diff), while Abdul Wasey raises the real design-system risk: 'Dragging 1 card shouldn't quietly change all 20 screens.' One of the three captured replies is an unrelated ad. Sentiment: genuine curiosity with an unresolved component-scoping caveat. 27 replies, 799 likes, 1,082 bookmarks, 45.8K views.

## 💡 Takeaway

Reusable agent skills are becoming the distribution unit for dev tooling - a free OSS skill is how Builder.io puts its Design surface inside every coding agent.
