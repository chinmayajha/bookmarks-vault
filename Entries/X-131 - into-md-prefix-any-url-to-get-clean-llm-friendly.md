# into.md: prefix any URL to get clean, LLM-friendly markdown

**[Open original ↗](https://x.com/timolins/status/1962543056152145928)** · `Timo Lins` · 2025-09-01 · 49 replies · 1.1K likes · 120.4K views · ⭐ high follow-up

## 💬 Essence

OP shipped a weekend fix for the missing 'Copy as markdown' button: type into.md/ in front of any URL to get clean, LLM-friendly markdown for any website or docs page. His self-thread adds it's free, built with Nitro on Vercel with ISR caching, that most content sites aren't SPAs, that he added an Accept-Language header after locale complaints, and that it's Readability then Turndown under the hood. Replies marvel at the speed, flag that it fails on SPAs and sometimes switches page locale, and one maker points to a similar tool (content-parser.com) that auto-downloads the markdown.

## 💡 Takeaway

Tiny utility, big bookmark count; caveats about SPAs and locale are in the replies.
