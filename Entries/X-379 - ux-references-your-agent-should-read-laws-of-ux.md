# UX references your agent should read: Laws of UX, Nielsen, GOV.UK, Inclusive Components, Apple HIG

**[Open original ↗](https://x.com/nurijanian/status/2113600826874950119)** · `George from 🕹prodmgmt.world` · 2026-10-23 · 13 replies · 15 reposts · 370 likes · 651 bookmarks · 20.9K views

## 💬 Essence

George lists five sources to give a design agent: Laws of UX, Nielsen's 10 usability heuristics, the GOV.UK Design System, Inclusive Components by Heydon Pickering and Apple's Human Interface Guidelines. After the prototype builds, ask the system which usability heuristic each screen breaks, then make it highlight the exact element on the screen that causes each problem. A self-reply promotes his PM harness for Claude Code and Codex. Replies add the WAI-ARIA Authoring Practices for keyboard behaviour, a GOV.UK check (after an invalid form submit, focus the error summary and link each error to its field, tested by keyboard), and the point that heuristics do not stop an agent putting three primary buttons together.

## 💡 Takeaway

A short reading list plus a two-step critique loop you can paste into a design prompt.
