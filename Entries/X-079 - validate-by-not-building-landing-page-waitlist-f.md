# Validate by NOT building: landing page + waitlist first

**[Open original ↗](https://x.com/Layton_Gott/status/2019239488212578440)** · `Layton Gott` · 2026-02-05 · 541 replies · 514 reposts · 10.1K likes · 422.1K views · 2.7K … · ⭐ high follow-up

## 💬 Essence

Layton's validation playbook: don't build the product - make a landing page, describe the problem it solves, add a 'join waitlist' button; if nobody signs up you just saved yourself 3 months. His thread agrees that people market things for roughly that long before giving up because the problem was never validated. Replies add the caveat: TJ built a page, got 60+ signups, spent 4-5 months building, and then nobody used or paid for it - arguing monetization should start from day one - while another says no MVP should take 3-4 days; 10,066 likes and 2,709 bookmarks.

## 💡 Takeaway

Classic validation advice with the perfect rebuttal in replies (waitlist signups are not payment) - both halves worth saving.
