# REA babysitting prompt turns free GLM-5.3-Flash into a reverse-engineering analyst

**[Open original ↗](https://x.com/qwerty__cs/status/2111325567077544219)** · `qwerty__cs` · 2026-10-17 · 72 replies · 274 reposts · 2.1K likes · 3.1K bookmarks · 146.6K views

## 💬 Essence

The 'REA Reverse Engineering Babysitting Tutorial' is a four-step workflow: install OpenCode, pick the free GLM-5.3-Flash model, paste the prompt shown in the image, and let the agent drive REA (Reverse Engineer Anything). The prompt is a structured operating contract - objective, requirements, decisions, work state - demanding evidence anchors (path/line/address/md5), four-part reports, and strict rules about worktrees, file writes and uploads. Replies are split: a reverse engineer with IDA experience calls it overhyped versus IDA MCP + AI, while others confirm Frida memory hooks work until Zhipu patches the free window. The best tips are to split decompilation into a module inventory then per-module deep dives (context truncation), and to expect queue variability on the free tier.

## 💡 Takeaway

A reusable prompt structure for agent-assisted RE, not a magic button - treat the 'no bans' claim skeptically and verify findings against real tooling.
