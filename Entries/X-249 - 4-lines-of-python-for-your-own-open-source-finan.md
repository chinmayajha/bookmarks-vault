# 4 lines of Python for your own open-source financial advisor

## 💬 Essence

OP claims four lines of Python are enough to have your own fully open-source financial advisor: you need two API keys - OpenAI for the LLM and OpenBB for access to dozens of data vendors - with the code shared. He adds it lets users add external function-calling tools for data OpenBB lacks by default, points to the OpenBB platform path for anything with a valid Hub API key, and, because most commenters do not understand what is happening, links a post with Michael Struwig explaining how it works under the hood.
