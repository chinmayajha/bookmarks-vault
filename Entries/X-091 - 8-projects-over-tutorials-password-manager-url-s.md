# 8 projects over tutorials: password manager, URL shortener, scraper...

## 💬 Essence

Vivo's list says don't overcomplicate it: build a password manager (file handling, hashing), URL shortener (routing, IDs, persistence), Todo app with deadlines (CRUD, state), web scraper (requests, parsing, rate limits), CLI expense tracker (logic, files, edge cases), log analyzer (files, timestamps, patterns), a simple recommender using similarity rules (not ML magic) and an email automation script (SMTP, scheduling) - 'Projects. Not tutorials.' His thread reiterates projects over tutorials, master basics then scale. Replies endorse the simplification and add that a chat app introduces WebSockets; 3,809 likes and 5,262 bookmarks.
