# Agent tree component shows which agent spawned which

**[Open original ↗](https://x.com/flohoeller/status/2112150373565612534)** · `Flo` · 2026-10-19 · 85 replies · 114 reposts · 2.7K likes · 2.9K bookmarks · 143.6K views · 🎬

## 💬 Essence

Design engineer Flo demos an agent-tree UI component that visualizes parent/child agent relationships - who started whom. The 2.7K-like reaction is mostly design admiration for his component library, with practical questions about the stack (BaseUI, shadcn, Radix), whether a parent's cost includes its children, and requests to port it to Claude Desktop, t3 code and Supacode. Suggested improvements: keep the parent sticky while scrolling long child lists, and show children that outlive a stopped parent. No code or link is included.

## 💡 Takeaway

A strong interaction pattern for agent observability UIs - worth copying the tree idea, but the post is inspiration rather than a usable component.
