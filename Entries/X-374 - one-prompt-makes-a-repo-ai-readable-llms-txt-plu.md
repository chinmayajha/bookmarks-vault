# One prompt makes a repo AI-readable: llms.txt plus a Markdown page for every route

**[Open original ↗](https://x.com/kalashvasaniya/status/2114433628419879152)** · `Kalash` · 2026-10-24 · 45 replies · 50 reposts · 881 likes · 2K bookmarks · 64.9K views

## 💬 Essence

Kalash shares a prompt for a codebase: fetch scrolllaunch.com/prompts/ai-readable-site.md and carry out its prompt section on the repo, but show a plan before writing code. It is meant to handle SEO, AEO, GEO and ASO and to create a .md file for every page. He quotes govi's line that the future is full of markdown files. A self-reply links the prompt page, and another links directory submission at scrolllaunch.com. Replies mention dualmark.dev (AEO infrastructure for marketing sites). One sceptic says a markdown file per page does not make AI models recommend your site. Kalash agrees it is no guarantee, but says making content easier for AI to read does not hurt. He also suggests turning the prompt into a rule in Claude or Cursor.

## 💡 Takeaway

A cheap experiment for AI discoverability. Expect better readability, not guaranteed recommendations.
