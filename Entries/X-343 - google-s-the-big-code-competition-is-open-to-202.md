# Google's The Big Code competition is open to 2027-2029 grads, not 2026

**[Open original ↗](https://x.com/okbhaicool/status/2025257184146473034)** · `TryingToFindAGoodUsername` · 2026-02-21 · 11 replies · 8 reposts · 142 likes · 100 bookmarks · 10K views

## 💬 Essence

A quick signal boost for The Big Code, a Google coding competition hosted on HackerEarth. The important detail is eligibility: it is open to 2027, 2028 and 2029 graduates, and the poster - a 2026 grad - spends the thread complaining that his batch is excluded. Replies confirm the same frustration and ask whether this replaces Google Hash Code or Code Jam, which Google discontinued. For anyone in the eligible batches, the value is the direct HackerEarth link; for everyone else, it is a reminder to check graduation-year filters before investing time in a contest.

## 💡 Takeaway

Worth a look only if you graduate in 2027-2029; the thread is more useful for the eligibility warning than the competition itself.
