# Joggernaut: CI-speed skills built from OpenAI, Linear and Shopify fixes

**[Open original ↗](https://x.com/mattgapp/status/2124976587666063711)** · `Matt Gapp` · 2026-11-23 · 11 replies · 18 reposts · 328 likes · 522 bookmarks · 24K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Matt Gapp introduces Joggernaut, a set of skills that find the root causes of slow CI. It is based on learnings from teams at OpenAI, Linear, Shopify and others. His claimed results: OpenAI median CI from about 10 to 4.5 minutes, Linear about 87K runner-minutes a month saved, Shopify Ruby LSP from about 30 to 20 minutes with the same 18,329 tests, Sidelab from 68 to 15 minutes. At Boardy, PR caches had missed all year. Install in Claude Code with /plugin marketplace add usejog/joggernaut, then /plugin install jog@joggernaut, then /jog:ci-diagnose. For Codex, run npx skills add usejog/joggernaut -g -y -a codex. It is MIT licensed with no telemetry, and you do not need the Jog product. One reply asks for support beyond GitHub Actions.

## 💡 Takeaway

A ready skill pack for the CI-under-2-minutes trend. The numbers are the team's own claims.
