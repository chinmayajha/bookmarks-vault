# One command gives coding agents persistent memory via supermemory

**[Open original ↗](https://x.com/supermemory/status/2111558196494303327)** · `supermemory` · 2026-10-17 · 13 replies · 26 reposts · 488 likes · 398 bookmarks · 34K views · 🎬

## 💬 Essence

Supermemory's pitch is a single command - npx supermemory plugins - that adds persistent memory to coding agents, with a console for management. Replies surface the practical issues: copy-pasting the stylized Unicode command from the tweet fails, people want to know if it is open source and how it compares to Hindsight, and one user argues stale memories should decay rather than be related to new ones because they cause drift. The positive replies focus on how hard memory is and how much a one-liner helps.

## 💡 Takeaway

A low-friction memory layer worth testing, but the command must be retyped (not copied from the styled text) and memory-decay policy is still an open design question.
