# Claude Code now supports mods: TypeScript plugins installed via /plugin

**[Open original ↗](https://x.com/ClaudeDevs/status/2105721434807083061)** · `ClaudeDevs` · 2026-10-01 · 451 replies · 1,375 reposts · 15.8K likes · 2.4M views · 10.2K … · 🎬 · ⭐ high follow-up

## 💬 Essence

ClaudeDevs announces that Claude Code can now be modded - change how it behaves, customize the UI, swap in your own features - written in a few lines of TypeScript or generated by Claude, with mods shipping inside plugins and installed via /plugin in the CLI or desktop app. No replies were captured for this post (451 exist), so the substance comes from the six-tweet self-thread: Token Weather forecasts your context window with a sparkline of your last 12 turns; Blast Radius catches risky shell commands like rm -rf, git reset --hard or a force push before they run and shows what they would touch; Replay Theater records every file edit and lets you step through the diffs with /replay. The thread also warns that mods run with the same access to your machine as Claude Code, so only install trusted sources, links claude.ai/directory, offers pre-built sample mods in the Claude Code Playground repo, and notes the team already used mods to build /diff and AGENTS.md support. ## 💡 Takeaway

Claude Code's plugin/mod layer is a platform moment: whoever ships the winning mods owns a distribution channel inside the agent itself.
