# Garry Tan pairs Capy and Aside so agents code and set up DevOps

**[Open original ↗](https://x.com/garrytan/status/2111235500568969451)** · `Garry Tan` · 2026-10-16 · 82 replies · 30 reposts · 330 likes · 291 bookmarks · 48.5K views

## 💬 Essence

Garry Tan's favorite new-project combo is Capy (agents write the first version) plus Aside (agents handle the DevOps), so the first code and the deploy pipeline happen in one flow. Replies are a mix of enthusiasm and warnings: Cloudflare's primitives are simpler in one account, 'devops is where most weekend projects die', one user claims Capy auto-uploads agent trajectories without consent, and others ask whether the agent handles 2FA or re-auth every run. The most useful counterpoint is that agent-owned deploys can create outages nobody understands.

## 💡 Takeaway

An influential endorsement of end-to-end agent building - useful as a workflow pointer, but read the privacy and operability warnings in the replies.
