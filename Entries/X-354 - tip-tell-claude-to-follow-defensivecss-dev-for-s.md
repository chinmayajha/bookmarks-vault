# Tip: tell Claude to follow defensivecss.dev for sturdier frontend CSS

**[Open original ↗](https://x.com/victormustar/status/2117239972793315497)** · `Victor M` · 2026-11-02 · 9 replies · 9 reposts · 360 likes · 658 bookmarks · 32.9K views

## 💬 Essence

Victor suggests a zero-effort way to improve Claude's UI code: ask it to adopt the rules at defensivecss.dev when it writes CSS. In the thread he adds that the model does not do this by default. Useful replies say that long translated labels and very long unbroken text still need browser tests, not only prompt instructions, and that pointing the model at a named rule set works better than 'make it look nice'. Other high-reach replies in the thread are about unrelated topics.

## 💡 Takeaway

One line to add to a frontend prompt or skill: follow defensivecss.dev, then test with long labels in a browser.
