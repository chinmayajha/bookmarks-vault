# Things Claude Code won't tell you: Firebase>Supabase, Render>Vercel...

**[Open original ↗](https://x.com/prasann_pandya/status/2032101698424934504)** · `Prasann Pandya` · 2026-03-12 · 227 replies · 198 reposts · 3.8K likes · 285.6K views · 5.7K bookmarks · ⭐ high follow-up

## 💬 Essence

Prasann's list of opinions Claude Code won't give you: Firebase much cheaper and better than Supabase for most use cases, Pinecone better than Pgvector, Render better and cheaper than Vercel, Modal and Lambda better than Celery, FastAPI better than Node, Expo better than Xcode for iOS - concluding this is why vibe coders can prototype but struggle to scale, and that this intuition comes from building and scaling products. His thread agrees on FastAPI and Pinecone but worries about infra. Replies call them judgment calls (pgvector if you already need an RDBMS), add Neon/Supavault branching, note Hetzner is 1/3 the price of Render, and defend Xcode with Claude; 3,790 likes and 5,670 bookmarks.
