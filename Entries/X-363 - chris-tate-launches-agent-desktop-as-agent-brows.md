# Chris Tate launches agent-desktop as 'agent-browser for your whole computer'

**[Open original ↗](https://x.com/ctatedev/status/2116323148706771302)** · `Chris Tate` · 2026-10-31 · 594 replies · 1.2K reposts · 10.2K likes · 12.5K bookmarks · 1.5M … · 🎬 · ⭐ high follow-up

## 💬 Essence

Chris Tate announces agent-desktop: computer use for any coding agent on macOS, Windows and Linux, running in the background while you keep working, with agents using the computer in parallel and each one getting its own cursor. A self-reply says to star and fork it, and that it was built by Lahfir, who just joined the Vercel Labs team (repo vercel-labs/agent-desktop). The post is the big launch one: about 10K likes, 12.5K bookmarks and 1.5M views. Replies ask how it compares with cua.ai's cua-driver and whether it can work with agent-browser, and some users plan to test it against Cua and Codex computer use. See the feature thread and the cubench numbers for details.
