# brandpull: npx CLI that pulls any site's branding kit in 10 seconds

**[Open original ↗](https://x.com/notsurajgaud/status/2058439040056389871)** · `Suraj Gaud` · 2026-05-24 · 8 replies · 10 reposts · 112 likes · 27.3K views · 190 bookmarks · 🎬

## 💬 Essence

Suraj Gaud introduces brandpull, an npx CLI that pulls any website's branding kit in about 10 seconds for agents and humans ('npx brandpull'). The self-thread adds the GitHub repo (suraj-xd/brandpull) and a second project link (Shoogle, a shadcn UI components and blocks search engine). Replies are positive and competitive rather than critical: Lokendra says he was 'thinking of something similar but on ui where user can search brand of any site and it lists all of its components like cards, tabs, dialog etc', Bharath shares his own attempt (typescrape.vercel.app), dhru plans to use it 'fossure' to fix a landing page, and the rest are short praise ('okay thats VALUE', a goat emoji). 8 replies, 112 likes, 190 bookmarks, 27.3K views.

## 💡 Takeaway

A tiny CLI returning structured branding JSON - handy whenever an agent-built page needs a real site's colors, fonts and logos without a signup.
