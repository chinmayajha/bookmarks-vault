# Phone-use plus OpenAI's Decisions API lets an agent choose its next action 10x faster

**[Open original ↗](https://x.com/abdullababakre/status/2107706550173434303)** · `Abdulla Ababakre` · 2026-10-07 · 3 replies · 1 repost · 83 likes · 67 bookmarks · 5.5K views · 🎬

## 💬 Essence

Abdulla Ababakre pairs phone-use, his agent that operates a phone, with OpenAI's new Decisions API, which lets an app choose the right model, tool or action in near real time. OpenAI says Decisions is up to 10x faster than GPT-6 Luna through the Responses API, and the combo is aimed at the step where a phone agent has to decide what to tap next without a full model round-trip. Phone-use currently runs on Ababakre's own device cloud, with a local version promised soon. The thread is tiny, but the one substantive question - whether it can drive a physical iPhone rather than a hosted device - points at the gap between a demo and a product.

## 💡 Takeaway

A promising latency fix for phone agents; the missing piece is local/physical-device support, which is still promised rather than shipped.
