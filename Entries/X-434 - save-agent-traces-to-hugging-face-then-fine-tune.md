# Save agent traces to Hugging Face, then fine-tune smaller models on them

**[Open original ↗](https://x.com/NielsRogge/status/2124925928606445693)** · `Niels Rogge` · 2026-11-23 · 1 reply · 2 reposts · 21 likes · 34 bookmarks · 1,867 views · ⭐ high follow-up

## 💬 Essence

Niels Rogge links the Hugging Face guide on agent traces. His advice: if you run agent work with frontier models, save the traces to Hugging Face. Later you can fine-tune smaller and cheaper open models on them. He names Qwen3.5 4B, Qwen 3.8 and Inkling-2 Mini. He says this saves a lot of money and runs fast, and a tutorial is coming. One reply asks about the missing reasoning traces from closed frontier models. The capture has no answer.

## 💡 Takeaway

A cheap route from frontier-model agent logs to a smaller model. The missing reasoning traces are the open question.
