## 💬 Essence

Gregor Zunic shows Browser Use + Jev = Ultrafast: a flight search took 7 seconds and cost $0.0039, using a new action space every step, a DOM state space and a small LLM fallback to type. He built a tiny open-source browser agent (the video is at 1x speed) and explains how it works in the follow-up. Replies lament that there still aren't broadly available flight-search APIs so agents must use computer use before GTA 6, and say they're excited to try it; 9,115 likes, 9,967 bookmarks and 3.2M views.
