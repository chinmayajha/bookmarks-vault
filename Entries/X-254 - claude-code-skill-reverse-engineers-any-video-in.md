## 💬 Essence

Pratzyy's Claude Code skill /dissect takes any video apart and writes a recipe for remaking its format, demoed left-vs-right on a Kurzgesagt short. The self-thread expands the pitch: it breaks down picture (every cut, shot, caption style, transition), words (transcript, hook, story beats), voice (pace, pauses, pitch), sound (music, SFX, loudness) and audience (most-replayed moments, top comments), accepts YouTube/X/Instagram/TikTok links, and emits one blueprint .md anyone or any AI can follow; install is '/plugin marketplace add 0xpratzyy/dissect' and it is free/open source.
