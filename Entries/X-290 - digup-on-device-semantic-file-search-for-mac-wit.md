# DigUp: on-device semantic file search for Mac with EmbeddingGemma 2

**[Open original ↗](https://x.com/_ARahim_/status/2108649742217679257)** · `Abdur Rahim` · 2026-10-09 · 15 replies · 62 reposts · 406 likes · 516 bookmarks · 17K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Abdur Rahim ships DigUp, a free open-source Mac app for semantic file search: it runs Google DeepMind's EmbeddingGemma 2 on-device, so you describe a video moment, podcast minute, PDF page, photo or chunk of code in any language and dig it up (github.com/ARahim3/DigUp). His self-thread notes love from r/LocalLLaMA and a coffee-support link. Replies propose combining the index approach with FSearch, which the author will look at; the rest are ads. 15 replies, 406 likes, 516 bookmarks.

## 💡 Takeaway

On-device multilingual embedding search over local files - a good reference for building private RAG over personal media.
