# Read a competitor's funnel and conversion values from their public GTM container

**[Open original ↗](https://x.com/googlewaqas/status/2117613798370545971)** · `Waqas | Ex-Google` · 2026-11-03 · 119 replies · 337 reposts · 5.7K likes · 15.9K bookmarks · 488.3K …

## 💬 Essence

An ex-Google ads specialist shows how to read a competitor's tracking from the public Google Tag Manager file. View the page source and search for GTM-, copy the ID, and open googletagmanager.com/gtm.js?id= with that ID. Search for AW- to see each Google Ads conversion, 'event' to see conversion names such as demo_booked or trial_started (their funnel in order), and 'value' to see what each step is worth to them. With a competitor's demo value you can decide whether you can outbid them on shared keywords. The thread ends with an agency pitch. Replies add that it only works if the container is not restricted, that server-side GTM hides it, that an old tool called GtmSpy did this, and that you should lock down your own container.

## 💡 Takeaway

A quick 10-minute recon trick for any competitor site. The post is also a lead-generation pitch, so treat the framing with care.
