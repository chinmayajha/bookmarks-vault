# Best tools to extract a webpage as markdown for an LLM

**[Open original ↗](https://x.com/DhravyaShah/status/1784501131168936083)** · `Dhravya Shah` · 2024-04-28 · 1 reply · 107 likes · 5.7K views

## 💬 Essence

Answering 'what is the best way to extract the main content from a webpage as markdown to give to an LLM', OP lists firecrawl.dev, r.jina.ai and Mozilla Readability (repo linked), and says he is building his own for git.new/memory, open-sourcing it within about 30 minutes. The captured reply says Jina has not been great in tests, Readability is good but markdown formatting came out wrong, and Firecrawl is paid.

## 💡 Takeaway

Quick comparison of the webpage-to-markdown stack, with a new open-source entrant promised in-thread.
