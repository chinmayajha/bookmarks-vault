# Make projects run in dev with no setup; use one secrets-manager key everywhere else

**[Open original ↗](https://x.com/davis7/status/2115196138894893196)** · `Ben Davis` · 2026-10-27 · 49 replies · 22 reposts · 1.1K likes · 688 bookmarks · 49.9K views

## 💬 Essence

Ben Davis recommends designing projects so they run in development without setup or env vars. When you need real environment values, use a secrets manager so you only need one key. He names Infisical as the best he has found. Replies add alternatives: varlock.dev (AI-safe .env files), dotenvx (commit encrypted env files so teams sync without a cloud), Convex, and Vercel Environments. The Infisical team replies and asks for feedback.

## 💡 Takeaway

A simple rule for new repos: zero-config dev, one key for secrets. Compare Infisical, varlock and dotenvx.
