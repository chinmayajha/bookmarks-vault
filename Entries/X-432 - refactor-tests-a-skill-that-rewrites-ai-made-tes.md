# /refactor-tests: a skill that rewrites AI-made tests to a written standard

**[Open original ↗](https://x.com/zkMarek/status/2125520741709795671)** · `zkMarek` · 2026-11-25 · 11 replies · 17 reposts · 451 likes · 752 bookmarks · 31.8K views · 🎬 · ⭐ high follow-up

## 💬 Essence

zkMarek shares /refactor-tests, a skill in his skills repo. He says AI-written tests got so bad that some people say to delete them, and friends report suites that run for an hour. On one of his projects, three runs of the skill made the tests 10x faster. A big repo can take hours, so he suggests running it on every PR. He says the first run gave the biggest change. The skill uses test templates to avoid weak tests. When it finds a bug, it writes an ignored test and asks if you want to fix it. He made the demo video with Claude from one prompt. The same prompt is also on prompts.one-time-use.com.

## 💡 Takeaway

Same problem as the AGENTS.md testing rules: tests that restate the code. Expect slow runs on big repos.
