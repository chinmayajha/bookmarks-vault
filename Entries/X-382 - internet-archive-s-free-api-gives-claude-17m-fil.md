# Internet Archive's free API gives Claude 17M films and 14M recordings for edits

**[Open original ↗](https://x.com/ElliotPadfield/status/2113393903923581149)** · `Elliot Padfield` · 2026-10-22 · 70 replies · 241 reposts · 3.6K likes · 8.3K bookmarks · 243.9K views · 🎬

## 💬 Essence

Elliot says that if you edit video with Claude you can give it archive.org's free API (no key) and ask it to search the Prelinger and 78rpm collections for archival b-roll or period music. The collections include 10,000+ Prelinger films (public-domain stock footage), 187,000 78rpm records and 300,000+ live concert recordings. He suggests the clips suit artsy ads for tech. In replies, someone built an MCP for it (edigeh/broll-mcp), one user asks him to delete the post to avoid a tragedy of the commons, and others ask people to support the Internet Archive. A copyright caveat: footage can be public domain while a music recording can still get a Content ID claim.

## 💡 Takeaway

A free source of b-roll and old music for agent edits. Check each item's rights, and support the Archive.
