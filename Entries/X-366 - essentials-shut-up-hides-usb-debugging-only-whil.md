# Essentials 'Shut-Up!' hides USB debugging only while banking apps are open

**[Open original ↗](https://x.com/Dhananjay_Tech/status/2116069301929337252)** · `Dhananjay_Tech` · 2026-10-30 · 69 replies · 140 reposts · 1.4K likes · 1.5K bookmarks · 78.1K views

## 💬 Essence

Dhananjay shares an Android tip for developers whose banking and UPI apps break when USB debugging is on. The Essentials app (open source, free, made by Sameera, repo sameerasw/essentials) has a 'Shut-Up!' feature that hides Developer Options and USB and wireless debugging only while chosen apps are open, then turns them back on when you close the app. The screenshot shows the app picker with Aadhaar, Axis Mobile, iMobile, OneCard, RailOne, SBI Card and YONO SBI enabled. In the thread: install it, search 'Shut up', select the app and add a shortcut to the home screen, then launch the app from that shortcut. Replies list alternatives: Geto (T31n/Geto, also on F-Droid), SU_IMD, and IMD from F-Droid, which works with Shizuku and toggles on its own. Caveats: some apps detect Shizuku or Essentials and refuse to run. One reply says Android 17 QPR1 fixes this developer-settings problem.

## 💡 Takeaway

A free fix for banking apps that block USB debugging. Test each app, since some detect Shizuku.
