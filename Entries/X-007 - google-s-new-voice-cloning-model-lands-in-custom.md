# Google's new voice-cloning model lands in Custom Voices

**[Open original ↗](https://x.com/jastephx/status/2103177172189929613)** · `Jason Stephen` · 2026-09-24 · 49 replies · 41 reposts · 604 likes · 48K views · 707 bookmarks · ⭐ high follow-up

## 💬 Essence

Jason Stephen nudges people to try the new voice-cloning model at ai.dev/generate-speech. His thread helps users find it under 'Custom Voices', discusses expected latency and notes some features are API-key-only with Google-subscription support coming next month. Replies report clones disappearing between sessions (Alex Volkov couldn't find his before the Thursdai pod), say latency is too high for voice agents (550-1200ms), complain a Google AI Pro subscription still demands an API key, and ask how commercial use works when the API requires a consent phrase from the voice owner.

## 💡 Takeaway

Early-adopter friction map for Google's voice cloning - availability, latency, subscription/API gating and consent rules.
