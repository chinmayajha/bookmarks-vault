# I got tired of copy-pasting LeetCode solutions, so I built this

**[Open original ↗](https://www.reddit.com/r/LeetcodeDesi/comments/1qvepw5/i_got_tired_of_copypasting_leetcode_solutions_so/)** · `u/NeelBansal` · 2026-02-04 · ↑119 · 20 comments

## 💬 Essence

OP was grinding LeetCode for internships and kept forgetting solved problems, so he built Leetion, a free Chrome extension that pushes each solved problem into a Notion database — name, difficulty, tags, solution code, spaced-repetition review date and self-rated confidence — plus a website and Firefox add-on, with no accounts or paid tiers. Replies are enthusiastic ('downloading this', 'I had this exact idea but couldn't finish it vibe-coding'), one user points out the site claims open source in the header but 'soon to be open source' in the footer and asks for a GitHub link, and someone offers the counterpoint that you can already see solutions via LeetCode's submissions tab. OP answers setup questions and says he's posted it before because so many people keep asking.

## 💡 Takeaway

A niche but validated tool: spaced-repetition review for problems you've solved, distributed free as a browser extension — plus useful signal on what makes such launches land.
