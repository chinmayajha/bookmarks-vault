## 💬 Essence

Oskar Wickström announces Bombadil 0.8.0 from Antithesis. Browser fuzzing is up to 4x faster and TUI fuzzing 2x faster. Binary compressed traces save disk space and I/O. He advises you to try it with chrome-headless-shell and links the doc page. One reply says 2026 is the year of property testing. The thread has little other discussion of Bombadil.

A speed-focused release of a property-based browser tester. Docs describe the headless setup.
