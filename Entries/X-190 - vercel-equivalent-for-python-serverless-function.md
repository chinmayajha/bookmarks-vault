# Vercel-equivalent for Python serverless functions?

## 💬 Essence

OP asks whether anything offers Vercel-like dead-simple deployment for Python serverless functions; replies recommend Modal, Vercel's own Python runtime, Render, Railway and - for ML workloads - Inferless, plus a joke about Google Scripts plus Sheets, while one newcomer replies 'we're working on it, stay tuned'. OP's follow-ups thank people, ask about limitations from a previous bad experience, and celebrate the frugal options.

## 💡 Takeaway

Crowd-sourced shortlist of Python serverless hosts - Modal, Render, Railway, Inferless.
