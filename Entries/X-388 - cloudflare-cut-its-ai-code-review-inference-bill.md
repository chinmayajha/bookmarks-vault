# Cloudflare cut its AI code-review inference bill 68% with prompt caching and model routing

**[Open original ↗](https://x.com/Cloudflare/status/2112280767308918908)** · `Cloudflare` · 2026-10-19 · 40 replies · 77 reposts · 992 likes · 1.8K bookmarks · 160K views · ⭐ high follow-up

## 💬 Essence

Cloudflare says the cost per run of its AI code reviewer doubled, so the team dug into token usage to find out why. Prompt caching and intelligent model routing cut the inference bill by 68% and sped up reviews. The post links a Cloudflare blog article about being obsessive about inference optimization. Replies add that tokens per review tripled and cost still fell, which shows cheaper models can do the job, and that another large saving may come from code mode or an equivalent. This is an unusually concrete cost write-up from a production system, close to the vault's inference-engineering plan.

## 💡 Takeaway

A real production case for prompt caching and routing as cost levers. Read the full blog post for the method.
