# A 15-year-old founder's full agent stack: t3, pstack, Notion, Linear and three cloud agents

**[Open original ↗](https://x.com/leodev/status/2110373428456820809)** · `Leo` · 2026-10-14 · 25 replies · 15 reposts · 333 likes · 522 bookmarks · 30.9K views · ⭐ high follow-up

## 💬 Essence

Leo, a 15-year-old founder shipping viral projects every one to two weeks, documents his whole setup: t3 code to remote into a Mac mini/Linux box, a custom pstack built for t3 and ov2, everything on a home server with Tailscale previews. Opus 5.5 is the daily driver, GPT-6.1 Sol reviews changes and sometimes does backend work, Haiku 5.5 handles codebase search and docs. Notion is long-term memory for both him and the agents, every thread starts as a Linear issue (even tiny fixes) so state is tracked and linked to the PR, and agents must test in a browser. He adds anti-slop oxlint rules, Paper for design, a mix of Capy/Hoplite/Devin for cloud work, Grok bot for managing agents, and Convex when a backend is needed. The most-asked question is for his custom pstack; his answer is to give the post to your agent and have it adapt the setup.

## 💡 Takeaway

Less a tool list than an operating model: one issue per thread, explicit memory, model specialization and browser-verified changes - copy the structure, not the exact stack.
