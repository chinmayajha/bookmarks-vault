# try.cloudflare.com blows up: free tunnels pitched at vibe coders

## 💬 Essence

Suganthan posts try.cloudflare.com ('What a time to be alive') as the internet discovers Cloudflare's free quick tunnels. His thread clarifies: ngrok has tunneled localhost for years, CF quick tunnels aren't new either, but Cloudflare is clearly aiming this at coding agents - scripts and agents can grab the URL directly instead of scraping logs, with JSON output - and CF later updated the landing page. Replies mostly roast the design ('feels vibe coded'), note tunnels have existed ~10 years, and share that Codex just started doing it for them; 11,772 likes, 15,703 bookmarks and 3M views.

## 💡 Takeaway

The viral moment of tunnels-as-agent-infrastructure, plus the counterpoint that this is old tech repositioned for agents.
