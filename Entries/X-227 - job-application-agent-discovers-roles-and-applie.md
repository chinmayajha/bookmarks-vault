# Job Application Agent discovers roles and applies for you

**[Open original ↗](https://x.com/vaibhavhome/status/2089580618191659488)** · `Vaibhav Arora` · 2026-08-18 · 95 replies · 2.5K likes · 506.3K views · ⭐ high follow-up

## 💬 Essence

OP ships a job-application agent: it discovers matching roles and applies on your behalf with full transparency, running 24 hours for you; jobappagent.com is live (upload resume plus preferences) while the local version stays open source on npm. In-thread he argues it is a mundane matching task agents should now do, that an agent is the skills, processes and infra around the model, that it uses Codex computer use under the hood (and you could rebuild it - that is why it is open source), and that browser-capable models are now very good at form completion. Replies joke that bots will now reject each other at scale, ask what it does beyond plain Codex computer use, and note that discovery is easy but reliable form completion needs browser state recovery across retries.

## 💡 Takeaway

Agent product at the job-apps x browser-automation intersection; the state-recovery critique is the real engineering point.
