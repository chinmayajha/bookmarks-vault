# Capy's Guided Reviews turn a big PR into chapters with a before/after overview

**[Open original ↗](https://x.com/0xluffy/status/2107593041519501477)** · `luffy` · 2026-10-06 · 31 replies · 46 reposts · 1K likes · 1.7K bookmarks · 141.1K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Capy added Guided Reviews: instead of dumping a big diff in file order, it opens with a before/after overview, groups files into chapters explained in plain language, and orders the core change first with database, tests and generated files last. It shipped in Capy 0.4.4 alongside marketplace plugins, custom models on your own key and desktop threads without a project. The demo is polished enough that the main reply thread is an accusation - this looks like Linear's guided diffs - and luffy answers that it was inspired by Linear but Capy had it in v1, lost it in v2 and is bringing it back with its own review agent. Either way, the interaction pattern is becoming table stakes for agent-era code review.

## 💡 Takeaway

A good default structure for reviewing agent-sized diffs - overview, chapters, core-first ordering - regardless of whether Capy or Linear ships it better.
