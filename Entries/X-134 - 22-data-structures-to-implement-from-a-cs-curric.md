# 22 data structures to implement from a CS curriculum

**[Open original ↗](https://x.com/ChShersh/status/1960609256681431281)** · `Dmitrii Kovanikov` · 2025-08-26 · 55 replies · 2.2K likes · 597.3K views · ⭐ high follow-up

## 💬 Essence

Responding to a trending debate, OP lists 22 data structures worth hand-implementing, from linked list and dynamic array through AVL/red-black/B-trees, segment trees, heavy-light decomposition, link-cut trees, DSU and suffix structures; the post itself quotes his own earlier 'Haven't y'all already done all that during your CS curriculum?'. The self-thread adds bonus points for doing them in C++, a follow-up algorithms list, that he did C++ and Java at uni and later reimplemented half in Haskell, and that it spanned six terms. Replies ask whether C or Haskell teaches computer thinking better, whether this is really one term, and where quadtree is.

## 💡 Takeaway

Debatable but genuinely useful implement-it-yourself syllabus; replies expose how ambitious it really is.
