# Built a C++ project for fun; drew feedback from IMC, Jane Street and HFT engineers

**[Open original ↗](https://www.reddit.com/r/quantindia/comments/1ubmeep/built_a_random_c_project_for_fun_ended_up_getting/)** · `u/Federal_Tackle3053` · 2026-06-21 · ↑319 · 56 comments

## 💬 Essence

OP, a Codeforces-grinding student with no finance background, built Pulse-Order — a C++20 low-latency trading system sim with binary market-data packets, an L2 order book, matching logic, risk checks, DPDK packet processing and benchmarks — and says it drew responses from an IMC engineer, Jane Street recruiters who spotted his profile, and HFT folks starring the repo. Replies press for details (recruiters plus GitHub stars, essentially), ask him to DM his learning plan, and one person building a Python toy engine is told Python is too slow for this — use C++/C/asm. Sentiment is mostly admiration ('Mad respect, keep up the grind', suggestion to write a blog) with a skeptical minority calling it star-farming or 'holy slop' vibe-coded work.

## 💡 Takeaway

Evidence that a public, well-built low-latency trading repo can pull recruiter and engineer attention at top HFT shops — and the exact stack that got it noticed.
