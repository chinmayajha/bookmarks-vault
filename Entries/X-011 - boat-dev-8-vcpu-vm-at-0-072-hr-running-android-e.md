# boat.dev: 8-vCPU VM at $0.072/hr running Android emulator + 60fps stream

**[Open original ↗](https://x.com/AniC_dev/status/2102785812635214139)** · `Anicet` · 2026-09-23 · 28 replies · 38 reposts · 518 likes · 38.8K views · 532 bookmarks · 🎬

## 💬 Essence

Anicet shows an 8-vCPU/16GB/125GB boat.dev VM simultaneously running an Android emulator, Chrome and a 60fps desktop stream at $0.072/hr, arguing frontier always-on agent workflows need stable, inexpensive, generous VMs. His thread defends the unit economics and reliability ('you'd question all of conventional cloud'), says CLI, API and SDKs give you a URL, and that the minimum charge converts into usage credits. Replies are skeptical - 'these numbers don't even make sense' - and ask about iOS support, whether desktop software is needed, how the hourly price compares with the flat $20/month plan, and whether it's box.ascii.dev or boat.ascii.dev.

## 💡 Takeaway

Competitive pricing reference for dev/agent VMs (including a $20/mo subscription option) - a useful infra benchmark.
