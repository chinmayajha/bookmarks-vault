# LeetCode contest problem appeared in Amazon's SDE OA

**[Open original ↗](https://x.com/avlmp03/status/1964599099749253309)** · `Aman 🧑‍💻` · 2025-09-07 · 13 replies · 640 likes · 43.2K views

## 💬 Essence

OP points out that problem 3 of today's LeetCode contest was asked directly in Amazon's SDE OA two months ago. Replies identify the technique as nearest-greater-left/right with a simple monotonic stack, some call it easy while others admit they only got brute force or reused trapping-rain-water code, one is encouraged to start contests, and another complains that SDE and SDE-intern OAs reuse the same questions.

## 💡 Takeaway

Evidence that contest problems recycle into OAs - do recent contests before interviewing.
