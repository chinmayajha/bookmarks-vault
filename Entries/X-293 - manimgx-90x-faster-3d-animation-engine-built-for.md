# ManimGX: 90x-faster 3D animation engine built for agents

**[Open original ↗](https://x.com/sinaatalay/status/2109045945149395421)** · `Sina Atalay` · 2026-10-10 · 66 replies · 294 reposts · 2.6K likes · 4.2K bookmarks · 162K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Sina introduces ManimGX, an open-source 3D animation engine built for agents: 90x faster than ManimCE (36s of 1080p60 in 3.1s; 11.5x ManimGL, 18.7x Blender Workbench, method in the repo benchmarks), Rust + wgpu core, compatible with Manim's Python API, one pip install with no system dependencies (no LaTeX/FFmpeg, 65-110MB), and it even runs in the browser via Pyodide and WebGPU. Agent-native touches: a manimgx inspect CLI that storyboards PNGs for the agent to check before rendering, 2D layout checks (cutoff, overlap, size), fully statically typed APIs, and an llms.txt try-it prompt. 66 replies, 2,610 likes, 4,184 bookmarks.

## 💡 Takeaway

The speed plus llms.txt plus inspect-loop combo is the template for making any renderer agent-operable.
