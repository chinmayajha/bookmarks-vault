# eve 1.0 is generally available: open-source framework for production agents

**[Open original ↗](https://x.com/eve/status/2122757457101681075)** · `eve` · 2026-11-17 · 15 replies · 104 reposts · 676 likes · 510 bookmarks · 93.3K views · 🎬

## 💬 Essence

The eve account announces eve 1.0, now generally available. You build agents on your own harness, ship multi-tenant and multiplayer agents, govern and trace sessions with Agent Runs, and render agent UIs with Next.js, Nuxt and other frameworks. The linked Vercel blog post says eve is open source, saves progress through the Workflow SDK so an agent resumes after a crash, and has native channels such as Slack, Teams, Discord and GitHub. Managed hosting runs on Vercel Workflows and Vercel Sandbox. Replies are mostly congratulations. One asks whether Agent Runs tracing costs extra, and the captured replies give no answer.

## 💡 Takeaway

Read the blog post before you pick eve over your own agent loop. Check the price of Agent Runs tracing first.
