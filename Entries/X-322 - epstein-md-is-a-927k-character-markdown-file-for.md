# Epstein.md is a 927K-character markdown file for banning AI design slop

**[Open original ↗](https://x.com/shipper_now/status/2110637576935891122)** · `Shipper` · 2026-10-15 · 138 replies · 167 reposts · 2.1K likes · 3.6K bookmarks · 440.4K views · 🎬

## 💬 Essence

Shipper released epstein.md, a 927,400+ character markdown file meant to stop vibe-coded UI from looking like AI slop: no box shadows, no emojis, no green 'LIVE' badges, zero blue-purple gradients, and a blocklist of 350 overused AI words (delve, vibe, seamless). It is the product of 11 months of eight-hour doomscrolling and continuous additions to their own vibecoder, and it is integrated into shipper.now. The reaction is split between people who want the file and people dunking on the name and on the launch video, which itself uses checkmark emojis and looks like the slop it claims to ban. Several replies are simply 'what .md?' - the post never links the file directly, which blunts the distribution.

## 💡 Takeaway

A memorable anti-slop ruleset with a self-inflicted naming and packaging problem; the content may be useful, but the launch is a case study in how a joke name can overshadow the artifact.
