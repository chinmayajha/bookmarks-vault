# The colleague-approved Rust starter stack

**[Open original ↗](https://x.com/codingmickey/status/1791173266087760246)** · `Kartik Jolapara` · 2024-05-16 · 8 replies · 262 likes · 25.4K views

## 💬 Essence

OP shares what a colleague told him at the start of his internship when he asked how to learn Rust: The Rust Book, Jon Gjengset's channel, Rust for Rustaceans, This Week in Rust, and the rust tag on Lobsters - noting it would work for anyone learning any new language because it is less about the language and more about the mindset (the point is in the second-to-last paragraph). Replies add Zero to Production as a great book, praise Jon's channel as a goldmine after basic projects, debate Rust vs Go, and suggest Discord and the official book.

## 💡 Takeaway

Tight, credible Rust starter kit spanning book, video, newsletter and community.
