# SlashDocs is Google Docs for the HTML and Markdown agents generate

**[Open original ↗](https://x.com/shashank_kr/status/2109600308825587994)** · `Shashank Kumar` · 2026-10-12 · 122 replies · 191 reposts · 1.4K likes · 957 bookmarks · 168.9K views · 🎬 · ⭐ high follow-up

## 💬 Essence

Shashank Kumar open-sourced SlashDocs, a collaboration hub for the HTML and Markdown documents agents now generate. It hosts decks, dashboards and reports in one place, with sharing, permissions and inline comments, and agents can read the feedback and update the same document instead of generating another file and another link. The proof is internal scale at Razorpay: 28,000+ documents created, and more than half of all documents generated there now live in SlashDocs. It is self-hosted, agent-agnostic and open source, with a hosted entry point at razorpay.com/slash-docs. Replies probe the obvious gaps - native Slack integration, how agents read comments (MCP?), comparison with Notion - and one reports a scroll bug, which is fair for a freshly open-sourced product.

## 💡 Takeaway

A sensible missing layer for agent output: one canonical, commentable document instead of a trail of regenerated files and links.
