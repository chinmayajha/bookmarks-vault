# React roadmap in 8 grouped steps

**[Open original ↗](https://x.com/0xBoneyBoi/status/1508146225865928706)** · `boney` · 2022-03-27 · 36 replies · 707 likes

## 💬 Essence

OP posts a React learning roadmap split into eight groups: Create React App, JSX and conditional rendering; functional components, lifecycle, useState and useEffect; useRef, contexts, useContext and useCallback; prop passing, higher-order components and React Router; Next.js SSR/SSG with Axios API calls; state management first with Context, then Redux; and React portals, Suspense and testing with Jest - closing with 'machines predict humans better than humans can predict themselves'. Replies thank him, joke that the algorithm already knows what they need, and save it for later.

## 💡 Takeaway

Clean, ordered React curriculum - the hook-by-hook grouping is the useful part.
