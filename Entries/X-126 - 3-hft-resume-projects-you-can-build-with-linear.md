# 3 HFT resume projects you can build with linear regression

**[Open original ↗](https://x.com/kshitijandquant/status/1970345055434260912)** · `Kshitij Anand` · 2025-09-23 · 3 replies · 7 reposts · 81 likes · 4K views · 126 bookmarks

## 💬 Essence

Kshitij says if you know linear regression you can build HFT-flavored resume projects: regress mid-price returns against order flow imbalance to test whether it captures immediate price pressure, regress price impact against trade size and liquidity to understand how your orders move the market, and model slippage as a function of latency, volatility and order size to quantify the cost of delay. He adds he's learning these too because he wants to explore that section of quantitative finance. Replies thank him and ask for resources on the systems behind quant/HFT - HPC, optimization techniques, custom network protocols; 81 likes and 126 bookmarks.

## 💡 Takeaway

Concrete, beginner-reachable project ideas linking basic stats to HFT concepts - good resume filler for quant aspirants.
