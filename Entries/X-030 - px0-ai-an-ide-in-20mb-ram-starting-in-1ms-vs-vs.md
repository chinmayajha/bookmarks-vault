# px0.ai: an IDE in 20MB RAM starting in 1ms vs VS Code's 1GB/7s

**[Open original ↗](https://x.com/arpit_bhayani/status/2099124464365756672)** · `Arpit Bhayani` · 2026-09-13 · 330 replies · 255 reposts · 4.1K likes · 488.5K views · 1.9K bookmarks · ⭐ high follow-up

## 💬 Essence

Arpit Bhayani hates VS Code eating 1GB and 7 seconds to start, so he built px0.ai, which does the same things in 20MB of RAM and starts in 1ms - arguing IDEs should become read-only but fast because the last time we edited code in an IDE was in 2025. His thread jokes about his own hypocrisy, ships v0.1.1 with Markdown rendering and gives the sudo px0 --update command. Replies include Hitesh Choudhary roasting that he'd claimed he wasn't building anything anymore, plus a request that Markdown rendering would make it super cool; 4,130 likes and 1,916 bookmarks on 488K views.

## 💡 Takeaway

A pointed product thesis - a read-only, instant-start IDE for the agent era - with real traction worth tracking.
