# Idea: a bot that hunts API keys leaked by vibe-coded apps

**[Open original ↗](https://x.com/PopPunkOnChain/status/2009254075670393069)** · `Pop Punk 🇺🇸` · 2026-01-08 · 3 replies · 183 likes · 20.8K views

## 💬 Essence

Replying to his own observation that you can get free API keys by opening the network tab on any vibe-coded app, OP proposes a bot: scrape every tweet containing the words 'vibe code' plus a URL, fetch the site and its network requests, look for outbound requests containing API-key patterns, and compile them into a free public database - 'you're a hero'. Replies are skeptical ('hm, maybe'), one says Claude will not extract data from anywhere despite two tries, and another simply says let them slop AI away.

Security-flavoured product sketch about vibe-coded apps leaking secrets - a sharp opportunity note.
