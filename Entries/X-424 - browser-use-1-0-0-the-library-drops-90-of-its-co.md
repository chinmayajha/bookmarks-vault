# Browser Use 1.0.0: the library drops 90% of its code and runs a Python REPL on raw CDP

**[Open original ↗](https://x.com/browser_use/status/2119983662162952278)** · `Browser Use` · 2026-11-10 · 50 replies · 105 reposts · 1.2K likes · 1.2K bookmarks · 201.7K views · ⭐ high follow-up

> ⏰ **Important:** Browser Use 1.0.0 deletes about 90% of the old library, and the team says it will ship fast. Pin the exact version with == before you upgrade.

## 💬 Essence

Browser Use releases 1.0.0 with the line that CDP is all you need. The team deleted about 90% of the old library, because a fixed state and action space makes agents worse. Now the agent writes a Python REPL on raw CDP. The post claims the same models do up to 50% better, 2 to 5x cheaper and 2 to 3x faster, and calls it a state-of-the-art web agent. The team will ship fast and asks users to pin the version with ==. A thread reply says the team is 5 people. Replies ask how it relates to browse harness, how it gates high-impact actions such as purchases, whether it is just code mode, and one says the team tried this a year and a half ago.

## 💡 Takeaway

This is a breaking rewrite. Pin the exact version before you upgrade, and check how your agent gates purchases.
