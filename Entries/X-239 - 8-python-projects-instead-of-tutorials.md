# 8 Python projects instead of tutorials

**[Open original ↗](https://x.com/vivoplt/status/2008418399395999834)** · `Vivo` · 2026-01-06 · 43 replies · 5K likes · 223.9K views · ⭐ high follow-up

## 💬 Essence

OP's argument: do not overcomplicate learning Python - build a password manager (file handling, hashing), a URL shortener (routing, IDs, persistence), a todo app with deadlines (CRUD and state), a web scraper (requests, parsing, rate limits), a CLI expense tracker (logic, files, edge cases), a log analyzer (files, timestamps, patterns), a simple recommender using similarity rules rather than ML magic, and an email automation script (SMTP, scheduling) - concluding 'the best way to learn Python? Projects. Not tutorials.' Replies agree you only learn by building and that tutorials create the illusion of learning; the author replies with quick affirmations.

## 💡 Takeaway

Project ladder mapping each build to the concept it teaches - one of the most-saved (6,012) learning threads.
