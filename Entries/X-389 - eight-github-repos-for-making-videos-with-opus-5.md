# Eight GitHub repos for making videos with Opus 5.5

**[Open original ↗](https://x.com/KinGao476942/status/2112729924943634602)** · `Kin` · 2026-10-21 · 144 replies · 1.2K reposts · 9.2K likes · 24.5K bookmarks · 834.8K …

## 💬 Essence

Kin lists eight repos for video work with Opus 5.5. 1) awesome-opus5-5-videos (about 7,100 stars): viral videos with their prompts. 2) lemo-opuscar (about 4,400): a Claude Code skill with 51 code short-film styles. 3) pdoom-video (about 3,000): a lyrics karaoke music video that renders 4K60 locally. 4) PDoomVideo (about 2,300): source for another video of the same song, to compare with 3. 5) mg-styles-15 (about 1,400): 15 motion-graphics styles with clips, prompts and code. 6) ClaudeAnimationBase (about 1,300): a starter pack for hand-drawn character animation with 31 expressions. 7) awesome-claude-5-5-videos (about 560): video workflows, 301 of them Opus-specific. 8) opus-video-prompts (about 510): Chinese-language cases with copy-paste prompts. Replies add pdoom.video (993 films and 501 prompts) and advise copying prompts to a local file, because repos can be renamed or change. The post has 24K bookmarks against 9K likes.

## 💡 Takeaway

A ready map of the Opus video ecosystem. Start with the prompt collections, and keep local copies.
