## 💬 Essence

jaimin points at the Appllama skills repo with a simple pitch - 'any app. any design. any interaction' - framed as the next step beyond a viral reverse-engineering demo: 'you think this is cool? wait until you find out about...' The skills are open-source and free, work with all models, and jaimin recommends Codex because it has native image generation, which helps when the target is a visual interface. The quoted post is just 'Reverse Engineer Anything. Software is done.' Replies ask which model to use and whether Appllama itself is now fully paywalled, which matters because the skills are only useful if the underlying service is still accessible.

## 💡 Takeaway

A free skill pack for cloning app flows and UI; the repo is the artifact, the 'software is done' framing is marketing.
